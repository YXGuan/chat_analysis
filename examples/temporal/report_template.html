How to read this prototype

Categories are fixed across the entire timeline. Every chat belongs to one category, so each stack sums to its week's total. Share mode divides by that user's recorded chats in that week; an empty week has no percentage. The comparison uses the first and last calendar windows of each user's own observed span. Windows must not overlap and must each contain enough chats before we show a change.

“A recurring focus” prefers a category with a similar share, then the most active weeks, among those with at least two chats in each window. A similar share means a change within 10 percentage points; recurring does not require a similar share. This is a descriptive comparison of this sample, with no statistical significance claim. Repeated topics may reflect a task or project rather than a lasting interest.

A “user” is an anonymous group with the same hashed IP, browser user-agent, and accepted language. Shared networks can combine people, and browser or network changes can split one person's history. This is an incomplete observed history. The source loader excludes empty chats, requires varied openings, keeps the first eight messages, and shortens each message to 2,000 characters. We do not infer identities.

Source: AllenAI WildChat-4.8M · ODC-BY. This report embeds its data and works offline. It sends no conversation text to an external model.
